# Grid Data Service

Status: planned — not yet implemented.

Caches hourly grid-mix and emission-factor data from AEMO (NEM + WEM), OpenNEM, and DCCEEW NGA Factors, versioned and time-series indexed for fast lookup by the [emissions-service](../emissions-service/README.md).

- **Database:** TimescaleDB
- **Port:** 8007

See the root [README.md](../../README.md) for how this service fits into the overall CarbonIQ architecture.
