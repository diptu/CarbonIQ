# Offset Service

Status: planned — not yet implemented.

Matches hourly/periodic consumption against renewables metadata (RECs, LGCs, GreenPower, PPAs) via the CER registry, preventing double-counting and producing residual (unmatched) emissions for the [emissions-service](../emissions-service/README.md).

- **Database:** PostgreSQL
- **Port:** 8009

See the root [README.md](../../README.md) for how this service fits into the overall CarbonIQ architecture.
