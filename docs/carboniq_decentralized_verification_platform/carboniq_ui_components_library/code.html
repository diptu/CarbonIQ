Usage Guidelines

Elevated Glass Surfaces

Surfaces must maintain a backdrop-blur-lg of at least 16px to ensure readability over atmospheric background shaders. Use 1px white borders at 10% opacity for standard containers.

#062C22 (60%) 16px Blur 1px Solid #FFFFFF (10%)

Interaction Feedback

Interactive elements should leverage the active:scale-95 transform and transition to a #00FF9D border-glow. Typography for metrics should use the Geist font for high technical clarity.
